## 一、功能总览

HolzynActor 以「**项目**」为工作单位：一个项目 = 一段世界观 + 一批角色 + 若干对话/记忆/事件，并随世界时钟持续演化。

## 二、核心功能说明

### 2.1 项目画廊与新增项目

- **画廊**：卡片网格展示项目（最近访问按更新时间倒序近似），支持搜索、删除、导出 `.holzyn` 包、导入 `.holzyn` 包；
- **新增项目**：
  1. 手工创建（填写名称/概要后进入，再补世界观与角色）；
  2. 上传文件解析（txt/md，AI 解析出世界观初稿 + 自动识别角色 → 预览确认 → 生成项目）；**未配置用户级 AI API 时页内预检提示**，一键跳转「设置 → API 配置」引导（解析失败同样弹窗引导），也可改用「空白新建」手动创建；
  3. 导入 `.holzyn` 项目包（幂等检测 projectUid，可选密码解密 API 配置）。
- **设置入口**：画廊顶栏「设置」、画廊操作区「设置」按钮、新增项目页头部「设置」按钮，均进入全局设置（`/settings`，API 配置为用户级默认）。

### 2.2 本地个人账户（需求 3）

- **首次启动**：路由守卫检测 `actor_local_account.onboarded`，未完成 → 跳转 `/onboarding` 向导；
- **账户信息**（全部选填）：
  - 展示类：昵称 / 头像 / 个性签名；
  - NPC 个性化档案：身份 / 职业 / 喜好 / 禁忌 + 自由长文本「个人档案」；
- **编辑入口**：顶栏账户菜单「本地账户设置」（`/account`）+ 设置 → 通用设置 → 「本地账户」卡片；
- **作用**：顶栏/侧边栏展示用户信息；**NPC 个性化**：单聊（及后端群聊）组装消息时，在角色 system_prompt 后追加「【你对用户的了解】…」系统消息，使角色基于用户档案做出定制化回应；档案为空则不注入。

### 2.3 项目仪表盘

- 欢迎区：项目名 / 题材标签 / 状态 + 快捷操作（进入对话 / 世界演化 / 新增角色）；
- 世界概况：世界观名称与概要、当前游戏时刻（第 N 日 + 速率）、世界模拟状态（推进/暂停）；
- 统计四卡：角色（特殊型/普通型）、知识库（文档/向量块/向量化率）、记忆（角色级/项目级）、AI 用量（Tokens/调用次数）；
- 最近动态：事件 / 行动 / 对话 / 记忆 合并按时间倒序，点击跳转对应页面。

### 2.4 世界详情

- 只读全文：题材 / 时代 / 地理 / 势力 / 规则体系 / 文化 / 历史 / 自由文本；
- 关联展示：项目级记忆（世界大事记）列表、删除；
- 修改入口：`/world/edit` 分节编辑并保存。

### 2.5 NPC 角色

- 角色列表（特殊型 NPC），新增 / 编辑 / 删除；
- 角色卡：AI 生成（`character_card_gen` 模板）→ 结构化 JSON 分节渲染 + system_prompt 预览 + 版本历史；
- 社会关系图、行动记录（决策/执行日志）。

### 2.6 对话（单聊）

- 左栏：单聊会话列表 + 项目角色（点击快捷开聊）；中栏：消息流；右栏：当前角色信息（结构化角色卡 / Prompt / 长期记忆，可手动抽取与删除）；
- **对话流（DeepSeek Harness 风格）**：
  - 居中内容列（748px），用户消息右侧气泡（主色底、22px 圆角）、AI 消息左侧气泡（Markdown 渲染：16px/24px、代码块高亮 12px 圆角）；
  - 生成中「Deep diving...」流光状态 + 15s 后显示耗时计时；
  - 空会话 / 空消息显示 Hero 空态（大标题 + 角色快捷入口 + 新建按钮）；
  - DSH 输入框：22px 圆角卡片、自动增高（最高 336px）、Enter 发送 / Shift+Enter 换行、世界事件工具按钮 + 发送箭头、自定义滚动条；
- 世界时钟控制（当前游戏时刻 / 暂停 / 手动推进）与「世界事件」注入（手填或 AI 生成）保留；
- **创建对话（场景化）**：新建单聊弹窗含「角色」「对话所在地」「当前时间（调用世界时间）」——
  所在地支持自由输入 + 从世界观地理文本启发式提取候选下拉，留空 = 通过手机等远程通讯软件对话（非面对面）；
  按「角色 · 所在地 · 世界时间」自动生成专属标题（可手动改，或「AI 重写」生成更贴切标题）；
  创建后进入空会话 Hero 空态；所在地/世界时间作为**场景快照**持久化并注入 NPC 回答
  （面对面场景强调环境描写、远程通讯体现通讯质感），会话头部/空态/列表展示，并可「编辑场景」随时调整；
- **群聊 UI 已隐藏**（新建对话框仅单聊；会话列表仅展示单聊；后端群聊代码保留）。

### 2.7 主题与外观（双主题分层 + 可换肤）

- **深浅双主题**：浅色 / 深色 / 跟随系统三种模式，顶栏月亮/太阳按钮快速切换；整个应用按 DSH 设计令牌分层（背景 / 层级卡片 / 边框 / 文本四级 / 阴影），彻底解决「全白无层次感」；
- **个性化主色**：设置 → 通用设置 →「主题与外观」提供 10 个预设色板（DeepSeek 蓝 / 星云青 / 紫罗兰 / 恋爱粉 / 玫瑰红 / 竹林绿 / 都市青绿 / 历史琥珀 / 悬疑暗红 / 霓虹靛）+ 自由取色器；
- **世界题材联动换肤**：进入项目时按世界观题材自动应用主色（恋爱→粉、言情→粉、科幻→蓝青、赛博朋克→青、奇幻/魔法→紫、都市/现代→青绿、历史→琥珀、古风→棕、悬疑→暗红、恐怖→暗红、武侠→竹林绿、仙侠→青绿、末日→灰），可关闭或对本项目单独覆盖；
- 持久化：主题偏好存本地 localStorage，刷新不丢失。

### 2.8 设置

| 子页 | 功能 |
|---|---|
| 通用设置 | 本地账户入口 + **主题与外观**（深浅模式 / 个性化主色 / 世界题材换肤 / 项目主色覆盖）+ 项目基本信息（名称/编码/概要）、世界时钟（速率/暂停/锚点/起始时刻）、群聊配置（每轮回复上限，全局）、.holzyn 导入导出、危险区（删除项目） |
| API 配置 | AI 模型 API 管理（OpenAI 兼容：DeepSeek 等）：新增/编辑/删除、设为默认、未保存与已保存连通性测试、用户级/项目级归属 |
| Prompt 模板 | 内置模板一览 + 用户级/项目级覆盖与重置 |
| AI 用量 | 用量统计（Token 输入/输出/缓存命中、调用次数、耗时，按项目/模型/时间过滤） |

> **双模式**：项目空间 `/project/:id/settings/*` 为项目级设置；首页顶栏「设置」进入全局 `/settings/*`（同一外壳与子页）——API 配置 / Prompt 模板为用户级默认（所有项目共享回退），AI 用量为**全部项目的总用量**（含「按项目」聚合），通用设置仅展示用户级项（本地账户 / 主题 / 群聊配置），项目专属卡片（基本信息/世界时钟/导入导出/危险区）在项目空间内配置。

## 三、导航（悬浮岛式侧边栏，需求 4）

```
┌──────────────────────────────┐
│  [总览] 项目仪表盘             │   ← 一级功能域项
│  [世界观] 世界详情             │
│  [角色] NPC 角色              │
│  [互动] 对话（单聊）           │
│  ▾ [设置]                     │   ← 可展开/收起父级
│      · 通用设置               │      子级缩进
│      · API 配置               │
│      · Prompt 模板            │
│      · AI 用量                │
└──────────────────────────────┘
```

- 视觉：圆角卡片、离边留白、柔和阴影（详见技术设计文档 §6.3）；
- 交互：分组父级点击展开/收起（箭头旋转动画，世界观/角色/知识/设置默认展开）；当前页品牌蓝高亮 + 左侧竖条 + 子级圆点着色；
- 导航结构（2026-08-18 恢复隐藏页后）：一级平铺「总览·项目仪表盘 / 互动·对话」+ 可展开分组「世界观（世界详情/世界演化/时间线）/ 角色（NPC 角色/普通人群）/ 知识（知识库）/ 设置（通用/API/Prompt/用量）」。

## 四、数据流要点

1. **首次启动**：`/onboarding` 向导 → account store 保存 → `onboarded=1` → 进入画廊；
2. **新建项目**：创建 → 生成角色卡（可选 AI）→ 配置 API → 开始对话；
3. **对话**：发送 → 落库 user + assistant 占位 → SSE 流式生成（注入角色卡 system_prompt + **用户档案** + 记忆/知识/环境上下文）→ 完成后记用量 + 异步抽取记忆 + 评估行动；
4. **世界模拟**（隐藏页仍可用）：世界时钟推进 → 角色行动 / 人群调度 / 事件生成。
