# HolzynActor 桌面端封装与发布说明 V1.0

> 2026-10-10 · 开源就绪「桌面端封装」落地。目标形态：**双击 exe → 拉起内置后端 → 弹出应用自己的窗口（Chromium 内核），体验与微信等桌面应用一致**；首次运行自动注入示例世界「青禾村」，开箱即得一个有角色、有地图、有记忆的活村庄。

## 1. 交付形态与总体架构

| 项 | 说明 |
|---|---|
| 壳 | **Electron**（`desktop/`，Chromium 渲染，与现有 Vue3 / Element Plus / ECharts / 地图完全兼容） |
| 后端 | Spring Boot fat jar（`backend/target/holzyn-actor-1.0.0-beta.1.jar`，内嵌前端静态资源）作 **sidecar** 子进程随包分发 |
| 运行时 | **jlink 裁剪 JRE**（`packaging/runtime`，约 62MB，只含运行所需模块）随包分发，用户无需装 JDK |
| 安装包 | NSIS 安装版 `HolzynActor-Setup-1.0.0-beta.1.exe` + 免安装便携版 `HolzynActor-Portable-1.0.0-beta.1.exe`（electron-builder 产出） |
| 数据目录 | `%LOCALAPPDATA%\HolzynActor\{data,uploads,logs}`——安装到 Program Files 等只读位置也可写；卸载不影响用户数据 |
| 端口 | 后端自动挑选**随机空闲端口**（不占用 8080，避免与开发者本机实例冲突） |

```
┌──────────────────────────── HolzynActor.exe ────────────────────────────┐
│ Electron 主进程（main.js）                                                │
│   ├─ spawn  sidecar：resources\runtime\bin\java.exe -jar backend\*.jar  │
│   │      env：HOLOZYN_ACTOR_DATA_DIR=%LOCALAPPDATA%\HolzynActor\data   │
│   │           SERVER_PORT=<随机空闲端口>  H2-TCP 关闭                     │
│   ├─ 轮询 http://127.0.0.1:<port> 就绪（≤120s）→                        │
│   └─ BrowserWindow 加载该地址（Chromium）← 首次启动自动注入「青禾村」      │
│   └─ 关窗 → taskkill 后端子进程树 → 退出（单实例锁）                       │
└─────────────────────────────────────────────────────────────────────────┘
```

## 2. 代码与脚本

| 文件 | 作用 |
|---|---|
| `desktop/main.js` | Electron 主进程：sidecar 启停、随机端口、就绪探测、窗口生命周期、错误对话框 |
| `desktop/preload.js` | 最小预加载桥（`window.holzynDesktop` 只读环境信息） |
| `desktop/package.json` | electron + electron-builder 依赖与 NSIS/portable 配置 |
| `desktop/build-desktop.bat` | 一键构建：build.bat(frontend+jar) → jlink 运行时(缺失时) → electron-builder |
| `desktop/build/icon.ico\|png` | 应用/安装包图标（源自 `docs/images/holzynactor-emblem.svg`，256px） |
| `packaging/make-runtime.bat` | jlink 生成裁剪 JRE（模块清单固化） |
| `packaging/runtime/` | 裁剪 JRE 运行时（构建产物，git 忽略） |
| `packaging/app-icon.svg` / `_icon-render.html` | 图标源与渲染页（Chrome headless 出 PNG → 封 ICO） |
| `packaging/app.ico` / `app-icon-256.png` | 图标产物（小体积，入库） |

## 3. 构建与发布

### 3.1 本地一键构建

```bat
desktop\build-desktop.bat        :: 全自动（含 build.bat + jlink + electron-builder）
```

分步（等效）：

```bat
build.bat                        :: 1) frontend+debug-frontend → static → fat jar
packaging\make-runtime.bat       :: 2) 裁剪 JRE → packaging\runtime
cd desktop
npm install
npm run pack                     :: 3a) NSIS 安装版 → release\HolzynActor-Setup-1.0.0-beta.1.exe
npm run pack:portable            :: 3b) 便携版   → release\HolzynActor-Portable-1.0.0-beta.1.exe
```

> 依赖：JDK 21（`JAVA_HOME`）、Maven、Node.js 18+。首次 `npm install` 需联网下载 Electron（约 100MB）；
> 国内网络可设 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`。

### 3.2 CI（GitHub Actions）

- `release.yml`：打 `v*` 标签自动在 **windows-latest**（自带 JDK21/Node/Inno 环境）构建 jar → jlink 运行时 → electron-builder → 上传安装包与便携版到 Release。
- `ci.yml`：push/PR 时并行跑 后端 Maven 测试（3110+ 全绿基线）与前端构建。

### 3.3 验证清单（发布前）

- [ ] `mvn test` 全绿（当前基线 **3120**：3110 + 桌面端 10 用例）
- [ ] 全新环境安装 `HolzynActor-Setup-*.exe` → 启动出窗口 → 首页出现「青禾村」（首启注入实证）
- [ ] 数据落在 `%LOCALAPPDATA%\HolzynActor\data`（非安装目录）
- [ ] 关窗退出、任务管理器无残留 `java.exe`；重复双击只聚焦已有窗口
- [ ] 设置-API 配置界面可用（桌面端仍需用户自配 AI 模型才能真正跑世界）

## 4. 运行机制与边界

- **AI 模型**：与网页版一致，**必须自行配置 AI 模型**（README 已强调）；程序化只作兜底。示例世界注入为纯数据导入，零 AI。
- **H2 TCP 调试端口**：桌面端关闭（`HOLOZYN_ACTOR_H2_TCP_ENABLED=false`），避免与开发者本机实例冲突；网页版/开发模式不受影响。
- **数据隔离**：桌面端与开发库（仓库 `data/`）各自独立；删除 `%LOCALAPPDATA%\HolzynActor\data` 可重置（重启重新注入示例世界）。
- **多实例**：Electron 单实例锁；后端随机端口 + 独立数据目录，互不干扰。
- **后端崩溃/超时**：弹窗给出 `holzyn-actor-console.log` 路径便于排障。
