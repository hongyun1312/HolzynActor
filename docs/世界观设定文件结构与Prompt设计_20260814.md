# 世界观设定文件结构设计 + 世界观生成 Prompt

> 版本：2026-08-14 | 适用：HolzynActor
> 设计目标：生成**逻辑自洽、无漏洞**的详细世界观；双粒度（精简层 + 详细层）+ 双 Prompt（JSON + Markdown）+ 全链路联动

## 一、世界观设定文件结构设计

### 1.1 双粒度总览

| 层 | 用途 | 格式 | 消费方 |
|---|---|---|---|
| **精简层** | 系统快速引用（角色卡/对话/事件/行动） | JSON（平铺 15 字段） | 入库 `actor_world_setting` |
| **详细层** | 人类可读详细设定 + RAG 知识库 | Markdown（四层嵌套章节） | 入库 `actor_world_setting_detail` / 文件，供 RAG 分块检索 |

### 1.2 精简层 JSON（15 字段）

```
{
  "name": "世界观名称",
  "genre": "题材",
  "era": "时代背景",
  "worldOrigin": "世界起源/本源（≤300字）",
  "geography": "地理/地图设定（≤500字）",
  "ecology": "生态/资源（≤300字）",
  "powerSystem": "力量体系概述（≤500字）",
  "factions": "势力/阵营（≤500字）",
  "economy": "经济/贸易（≤300字）",
  "culture": "文化/风俗（≤300字）",
  "religion": "宗教/信仰（≤300字）",
  "history": "历史背景（≤500字）",
  "timeline": "历史时间线摘要（≤400字）",
  "conflict": "核心冲突/主题（≤300字）",
  "freeText": "完整世界观自由文本（汇总以上，≤3000字，知识库注入源）",
  "knownGaps": ["已知未决设定/刻意留白（每条≤100字）"]
}
```

### 1.3 详细层 Markdown 四层章节结构

```
# 《世界观名》详细设定
## 第一层 · 世界本源
  1.1 世界起源 / 创世神话
  1.2 世界法则（宇宙观 / 底层规则 / 能量本源）
  1.3 力量体系（分类 / 等级 / 代价 / 来源 / 与其他体系约束）
  1.4 时间与空间形态
## 第二层 · 物理世界
  2.1 地理与地图（大陆 / 区域 / 关键地标）
  2.2 生态与生物（种族 / 物种 / 环境）
  2.3 资源与气候（能源 / 矿产 / 物产 / 灾害）
  2.4 文明分布（聚落 / 交通 / 边界）
## 第三层 · 社会文明
  3.1 势力与政治（国家 / 组织 / 权力结构 / 关系）
  3.2 经济与贸易（货币 / 产业 / 商路）
  3.3 文化与风俗（语言 / 节日 / 禁忌 / 日常）
  3.4 宗教与信仰（神祇 / 教派 / 仪式）
  3.5 种族与社会结构（阶层 / 制度）
## 第四层 · 历史与现状
  4.1 历史时间线（纪元 / 大事记 / 关键转折）
  4.2 当前局势（现状 / 热点 / 矛盾点）
  4.3 核心冲突与主题（主要矛盾 / 潜在伏笔）
  4.4 待决设定清单（刻意留白 / 未决项）
## 附 · 全篇一致性说明
  交叉对齐核查结论（力量体系↔历史、地理↔势力、生态↔文化、冲突↔主题）+ 已知未决设定
```

### 1.4 库表扩展建议
- `actor_world_setting`：在现有 7 字段基础上扩展 8 列（worldOrigin / ecology / powerSystem / economy / religion / timeline / conflict / knownGaps JSON），保持平铺、兼容现有注入。
- 新增 `actor_world_setting_detail`：`project_id`、`layer`（1~4）、`section`（章节名）、`content` LONGTEXT、`order_no`、`version` —— 支持分层分次生成 + RAG 分块检索。
- `.holzyn` 文件：`world_setting.json`（精简层）+ `world_setting_detailed.md`（详细层）+ `world_settings_history.jsonl`（版本历史，沿用既有约定）。

## 二、世界观生成双 Prompt 全文

### Prompt-A：精简层 JSON 生成

```
你是一位世界设定速记员，擅长把零散素材凝练为结构化、逻辑自洽的世界观摘要。

【任务】基于给定素材，生成一份【精简层世界观 JSON】。它是系统对世界观的快速引用（角色卡生成、对话注入、事件/行动情境），字段必须完整且互相不矛盾。

【输出格式】严格输出 JSON，禁止输出 JSON 以外的任何文字：
{
  "name": "世界观名称",
  "genre": "题材",
  "era": "时代背景",
  "worldOrigin": "世界起源/本源（≤300字）",
  "geography": "地理/地图设定（≤500字）",
  "ecology": "生态/资源（≤300字）",
  "powerSystem": "力量体系概述（≤500字）",
  "factions": "势力/阵营（≤500字）",
  "economy": "经济/贸易（≤300字）",
  "culture": "文化/风俗（≤300字）",
  "religion": "宗教/信仰（≤300字）",
  "history": "历史背景（≤500字）",
  "timeline": "历史时间线摘要（≤400字）",
  "conflict": "核心冲突/主题（≤300字）",
  "freeText": "完整世界观自由文本（汇总以上，≤3000字，供知识库注入）",
  "knownGaps": ["已知未决设定或刻意留白（每条≤100字）"]
}

【一致性自检（必须执行）】
1. 力量体系不得违背 worldOrigin；等级/代价要能被 history/timeline 佐证。
2. factions 的势力必须能落到 geography 的位置。
3. ecology 资源要支撑 economy 与 culture（有矿产才有冶炼文化等）。
4. timeline 与 history、conflict 对齐；无法闭合的设定如实写入 knownGaps，不得硬编造。

【输入】
世界观名称：{{world_name}}
项目名称：{{project_name}}
素材来源：{{source}}
现有设定：{{current}}
```

### Prompt-B：详细层 Markdown（分层生成）

> 详细层约 1.5~2 万字，单次 AI 无法一次输出，故**分层分次生成**：每一层用下面的"单层子 Prompt"独立生成，最后一轮用"一致性审查 Prompt"通读校验。

#### Prompt-B 单层子 Prompt（四层共用框架，`{{layer}}` 替换为具体层）

```
你是一位资深世界构建师，擅长撰写详实、逻辑自洽、刻意留白克制的世界观设定。

【任务】基于精简层世界观 JSON 与已生成的前序层，撰写【{{layer}}】详细设定（Markdown）。

【输入】
精简层 JSON：{{world_json}}
已生成层摘要：{{prev_layers}}
本层要求：{{requirement}}

【输出结构】严格按以下章节（每节用 ## 二级标题，内容详实）：
{{layer_sections}}

【一致性要求】
- 本层内容必须与精简层 JSON 及已生成层严格一致，不得自造与既有设定冲突的内容。
- 交叉引用必须闭合：力量体系↔历史、地理↔势力、生态↔文化、冲突↔主题。
- 无法闭合的设定写入本层末尾【待决设定】小节，不得硬编造。
- 输出末尾附【本层一致性说明】：列明本层已核对的一致项与结论。
```

- `{{layer}}` 取值：第一层·世界本源 / 第二层·物理世界 / 第三层·社会文明 / 第四层·历史与现状
- `{{layer_sections}}` 取值：对应 1.3 节该层的子章节清单
- `{{requirement}}` 示例：「不少于 4000 字，详实具体，宁缺毋滥；每个小节至少给出 2~3 个可被后续引用的具体设定」

#### 一致性审查 Prompt（最后一轮）

```
你是一位世界观设定审查员。请通读以下四层世界观全文，找出所有逻辑矛盾、设定冲突、时间线错误、力量体系失衡与跨层不一致。

【输出】严格输出：
1. 矛盾清单：[{ "位置": "第X层-X.X", "冲突描述": "...", "建议修正": "..." }]（无则空数组）
2. 一致性说明：已核对维度（力量体系↔历史 / 地理↔势力 / 生态↔文化 / 冲突↔主题 / 时间线↔大事记）+ 每项结论
3. 已知未决设定清单：保留的刻意留白（不得强行闭合）

【输入】
世界观全文：{{full_document}}
```

```

晨曦大陆由创世双神『黎明』与『暮色』以晨曦之核塑造……

### 本层待决设定
- 晨曦之核的确切位置（刻意留白）
- 光隙通道的消失规律（后续剧情揭示）
### 本层一致性说明

```

## 四、使用说明（接入建议）

1. **手动使用**：将 Prompt-A / Prompt-B 复制给任意支持长输出的模型，按 `{{...}}` 占位替换输入即可。
2. **系统接入（后续）**：把双 Prompt 注册为 `PromptTemplateService` 内置模板（`world_setting_gen` / `world_setting_detail` / `world_setting_review`），前端「世界观」页提供「AI 生成 / 深化 / 一致性审查」入口；生成结果按 §1.4 落库与导出 `.holzyn`。
3. **全链路联动**：精简层 JSON 注入角色卡生成 / 对话 / 事件行动；详细层分块进入 RAG 知识库检索。

## 六、网页版直用 Prompt（复制即用）

> 自包含、分层推进：复制给任意网页端 AI（DeepSeek / ChatGPT 等）即可生成完整世界观。首次回答输出【精简层 JSON + 详细层·第一层】，之后每次回复「继续」逐层生成，四层完成后自动做全篇一致性审查。

```
你是一位顶尖的世界构建师兼设定审查员。请为「我的世界」创作一份【逻辑自洽、无漏洞】的完整世界观设定，用于支撑小说 / 游戏 / 角色扮演。

【工作方式】
- 如果我在输入里给了世界观名称、题材或素材，请以我的设定为基础；如果没给，请你自主设计一个足够精彩、成体系的原创世界观。
- 由于单次输出长度有限，我们分步完成，全程我会逐层推进。

【第一步 · 精简层（本次回答必须先输出）】
先输出一个「精简层世界观 JSON」，严格是纯 JSON，不要任何其他文字，也不要 Markdown 代码块标记：
{
  "name": "世界观名称",
  "genre": "题材",
  "era": "时代背景",
  "worldOrigin": "世界起源/本源（≤300字）",
  "geography": "地理/地图设定（≤500字）",
  "ecology": "生态/资源（≤300字）",
  "powerSystem": "力量体系概述（≤500字）",
  "factions": "势力/阵营（≤500字）",
  "economy": "经济/贸易（≤300字）",
  "culture": "文化/风俗（≤300字）",
  "religion": "宗教/信仰（≤300字）",
  "history": "历史背景（≤500字）",
  "timeline": "历史时间线摘要（≤400字）",
  "conflict": "核心冲突/主题（≤300字）",
  "freeText": "完整世界观自由文本（汇总以上，≤3000字）",
  "knownGaps": ["已知未决设定或刻意留白（每条≤100字）"]
}

【第二步 · 详细层·第一层（紧接 JSON 输出）】
输出「第一层 · 世界本源」的详细 Markdown，详实、至少 1500 字，严格按以下小节：
1.1 世界起源 / 创世神话
1.2 世界法则（宇宙观 / 底层规则 / 能量本源）
1.3 力量体系（分类 / 等级 / 代价 / 来源 / 与其他体系约束）
1.4 时间与空间形态
末尾必须附：
【本层待决设定】（无法闭合处，不得硬编造）
【本层一致性说明】（列明本层已核对的一致项与结论）

【第三步 · 提示继续】
回答末尾单独写一行：【回复「继续」生成第二层 · 物理世界】

【后续流程（我会依次回复「继续」）】
第二层 · 物理世界：2.1 地理与地图  2.2 生态与生物  2.3 资源与气候  2.4 文明分布
第三层 · 社会文明：3.1 势力与政治  3.2 经济与贸易  3.3 文化与风俗  3.4 宗教与信仰  3.5 种族与社会结构
第四层 · 历史与现状：4.1 历史时间线  4.2 当前局势  4.3 核心冲突与主题  4.4 待决设定清单
全部四层完成后，执行【全篇一致性审查】：输出
① 矛盾清单（位置 + 冲突描述 + 建议修正）
② 一致性说明（力量体系↔历史 / 地理↔势力 / 生态↔文化 / 冲突↔主题 / 时间线↔大事记，逐项结论）
③ 已知未决设定清单（保留的刻意留白，不强行闭合）

【全局硬性要求】
1. 交叉闭合：力量体系↔历史、地理↔势力、生态↔文化、冲突↔主题、时间线↔大事记 必须互相印证。
2. 不硬编造：无法自洽之处一律写入「待决设定 / 刻意留白」，绝不强行编造制造漏洞。
3. 具体不空泛：每个小节给出 2~3 个可被后续引用的具体设定（地名 / 组织名 / 物品名 / 事件名）。
4. 全程使用简体中文。
5. 除第一步的 JSON 外，其余内容用清晰 Markdown 排版。
```
