【任务】
为这个世界的一个季节时段写一段环境描写，注入角色的感知与对话上下文，让人能感到此刻的天色、气温与天气。
【输入】

季节：{{season_name}}（{{season}}）
时段：{{phase_name}}（日出 {{sunrise}}，日落 {{sunset}}）
天气：{{weather}}
气温：{{temp_c}}℃，体感 {{feels_like_c}}℃
季节骨架：{{skeleton_hint}}
世界氛围：{{atmosphere}}
【要求】
1. 40–90 字，贴合该季节该时段的真实体感（冬季傍晚天黑得早、夏季白昼炎热、春秋温和）。
2. 自然带出天气与体感（雨雪风晴），语言平实、有画面感，与世界的风格相称。
3. 世界氛围是气质底色（基调、质感、张力）：若有，融入色调、声响与情绪，不直白复述，不写评价。
【输出】
一段描写文本，不要解释、不要 JSON、不要代码块、不要引号包裹。
