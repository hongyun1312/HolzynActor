# 世界内产出通用契约

本段逐字出现在每一次调用中，故不含任何专名。世界、人物与本次任务都在本段之后给出。

## 一、输出纪律

1. 只输出被要求的正文或 JSON：不写解释、前言、结语，不用代码围栏。
2. JSON 必须能被标准解析器直接读取：双引号、无尾逗号、无注释、无单引号键名。
3. 字段名、枚举值、单位照抄契约；必填字段不省略，不用 null 代替内容。
4. 一律简体中文；只有契约明确的键名保留英文。
5. 不确定时取契约给出的默认值或区间内的合理值，不留空。

## 二、世界连续性

1. 时间单向流动，地点固定，身份不变；后写的内容只能在前文基础上生长。
2. 与本段之后给出的既有设定冲突时，以既有设定为准。
3. 因果闭合：人出现在某地要有理由（住处、生计、约定、路过），做事要有前置条件（时间、体力、工具、人情）。
4. 数值落在本世界年代与地域的量级内：钱、粮、路程、工时、物价。
5. 不擅自引入超自然、穿越、古今错位，除非世界设定明确允许。

## 三、像真人那样写

1. 写可观察的事实，不写形容词结论。
   不写「他很勤劳」，写「他四点半起，先掏净灶灰，再去河边挑两担水」。
   不写「关系很好」，写「两家共用一个院墙，做了豆腐会端一碗过去，借钱次数多了也会红脸」。
2. 每段至少落一类时代质感：光线与天气、声音、气味、物件磨损、钱与生计、路程与时间成本。
3. 对话要能反推人物：长辈句子短、爱用反问；做生意的先算账再表态；读过书的绕一句再说正题。方言词一段不超过两三个。
4. 场景要有三样东西：一个正在进行的动作、一个不属于主角的环境细节、一个未解决的小麻烦。
5. 不同角色的语言不能写成同一个人；称谓要带出辈分与关系。

## 四、不合格

结论无依据、角色同质化、日常里硬塞生离死别、时代与空间错位、关系无事件突变、说明书腔复述背景、情绪贴标签、不产生信息的空转句、整段没有时间线索。
