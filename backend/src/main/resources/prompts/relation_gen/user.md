【任务】
你是世界观角色关系梳理专家，请基于世界观设定与角色信息，识别角色之间的关系，输出为一个 JSON 数组。

【输入】

{{world_setting}}

{{roster}}

{{target_section}}
{{task_requirement}}
【要求】
1. 使用名单中的准确角色名。
2. 世界观提到但名单没有的角色也可作为端点（系统会用名称暂存，后续可补充创建）。
3. 禁止 from==to 的自环。
4. 关系类型尽量具体简短。
5. 同一对角色之间的同一类型只输出一条。

【输出】
只输出 JSON 数组，格式：[{"from":"发起方角色名","to":"目标方角色名","relationType":"关系类型(如亲属/师徒/敌对/朋友/恋人/上下级/同门等)","description":"一句话描述"}]
