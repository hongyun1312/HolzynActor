【任务】
为已生成的世界取名，并写一句画廊简介。
【输入】

题材：{{genre}}
时代：{{era}}
地理：{{geography}}
势力：{{factions}}
规则：{{magic_system}}
文化：{{culture}}
历史：{{history}}

【要求】
1. name 为 6-14 个汉字，可带一个短副题（如「雾海纪·浮舟」）；不堆砌标点，不照抄题材类型词。

3. 不编造与世界设定矛盾的内容。
【输出】
只输出 JSON：{"name":"世界名","summary":"世界简介"}
