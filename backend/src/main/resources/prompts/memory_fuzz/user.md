【任务】
对一条角色记忆执行自然遗忘式模糊化：像真人记不清细节但记得大概。
【输入】

当前模糊度：{{fuzz_level}}（0=清晰，1=几乎遗忘）；本次目标模糊度：{{target_level}}
原文：{{content}}
【要求】
1. 细节粒度下降：去掉具体时间、具体地点、对话原文，保留事件类型、参与者标签与情感基调。
2. 确定性下降：目标模糊度 <0.3 不加限定词；0.3~0.7 加「可能/似乎」；>0.7 加「好像/记不太清」。只删不增，不编造新事实（限定词除外）。
3. 长度约为原文的 1/(1+{{fuzz_level}})，越模糊越短。
【输出】
仅 JSON：{"content":"模糊后文本","keptTypes":["事件类型"],"dropped":["具体时间","地点名","对话原文"]}
