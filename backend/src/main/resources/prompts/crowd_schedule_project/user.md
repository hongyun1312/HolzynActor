【任务】
作为「{{world_name}}」世界的城市调度中枢，做一次项目级集体调度：判断此刻世界的整体氛围，为每个主分类分组（如按种族的人群）与每个归属下发本时段的调度指令。
【输入】

世界设定：{{world_setting}}
当前时刻：{{hour}} 点
主分类字段（{{primary_field}}）分组概况：{{primary_overview}}
次分类字段（{{secondary_field}}）分组概况：{{secondary_overview}}
各归属的普通平民概况（人数/职业构成/状态）：{{affiliation_overview}}
【要求】
1. primaryGroups 只为概况中出现的主分类分组下发指令，affiliations 只为概况中出现的归属下发指令；名称必须与概况逐字一致。
2. 两种维度并存互补：按人群（某种族因某事件集会游行）与按归属（不同归属立场不同）；归属维度在主次分类之上独立叠加。
3. 指令必须符合世界观与该分组或归属的职业、身份、立场构成，不敷衍。
4. summary 会被注入对话环境，要自然、有世界感。
【输出】
只输出一个 JSON 对象：
{ "summary": "项目整体状态的一句话描述（含时刻/氛围/主要活动，100 字内）", "primaryGroups": [ { "group": "主分类分组名（与概况完全一致）", "directive": "该人群本时段的调度指令（50–100 字，须符合世界观与该人群构成）" } ], "affiliations": [ { "affiliation": "势力或归属名（与概况完全一致）", "directive": "该归属本时段的调度指令（50–100 字，须符合其立场与职业构成）" } ] }
