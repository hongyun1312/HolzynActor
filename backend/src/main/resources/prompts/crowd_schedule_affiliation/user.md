【任务】
作为「{{world_name}}」世界中「{{affiliation}}」的调度者，依据项目级调度指令与该归属的居民名单，为每位居民确定本时段的状态与行动。
【输入】

归属调度指令：{{directive}}
相关人群调度指令：{{group_directives}}
当前时刻：{{hour}} 点
居民名单：{{members}}
【要求】
1. 每位居民一条；name 与名单逐字一致，不遗漏、不新增；条数与名单人数完全一致。
2. state 从给定枚举中选；action 要同时符合其职业、身份、种族、归属指令、人群指令与当前时刻。
3. 不得敷衍，也不得让不同居民写出同一套行动。
【输出】
只输出 JSON 数组：
[ { "name":"居民姓名", "state":"idle|walk|stop|talk|rest 之一", "action":"该居民本时段的行动描述（20–60 字，第三人称）" } ]
