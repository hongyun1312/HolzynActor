【任务】
为一方世界绘制详细世界地图：把地点设定落实到空间——每个地点一个区域（圆心与半径）、道路连接、建筑摆放，以及每个角色的住所。
场景边长为 {{scene_size}}（格=米），坐标 x/z ∈ [0, {{scene_size}})。
【输入】

世界设定：{{world_setting}}
地点列表：{{locations}}
角色列表：{{characters}}
推荐布局：{{preset_layout}}
【要求】
1. 团状聚落：公共核心（祠堂、集市、水井、茶馆、凉亭）居中；民居围绕核心呈环带分布；生产用地（农田、梯田、菜地、林地）在聚落外围一侧；商业服务（医馆、铁匠铺、客栈、粮铺、茶摊）沿主路两侧近核心；村口地标（牌坊、渡口、学堂、山神庙）在村边或高地。
2. 临水布置：渡口、水磨、洗衣处在河畔（若有河）。
3. 道路网：主街贯穿核心并连接村口与村内，支路连接各民居群与商业点；路不穿过建筑。
4. 每地点一个区域，regionDesc 用口语描述（「村西口，进村第一景」），供角色感知。
5. placements 描述地点内的具体建筑（店铺、住宅、地标、农田），每个地点至少 1 条。
6. 有亲密关系（配偶、情侣、亲子、兄弟姐妹、亲属）的角色同住一间住所：只生成一间房，members 列出全部同住者；每角色恰在一个 homes[].members 中；每间住所一个户主（role=户主）；孤立角色独自一间。
7. 住所名用家中最体面的称呼（「沈家大宅」「李记面馆后屋」），roomLabel 写房间（「正房东间」）。
8. 全部坐标（区域圆心、摆放、住所）在 [40, {{scene_size}}-40] 内。
9. 区域两两不重叠：圆心距 ≥ r1+r2+4；半径 8–90。
10. 住所与摆放不落在河、路上（距道路中线 ≥ 路宽/2+3）；住所两两间距 ≥ 12。
11. 区域的 locationId 与地点列表一一对应；住所与摆放的 locationId 必须存在；homes[].members[].characterRef 必须来自角色列表。
【输出】
只输出一个 JSON 对象，键名照抄：
