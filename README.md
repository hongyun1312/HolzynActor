# HolzynActor · NPC 角色 AI 驱动模块

> **版本**：v0.1 Beta（开发者预览）

HolzynActor 是 Holzyn 全境世界生成项目中的「**NPC 角色 AI 驱动**」模块：以一段世界观设定为起点，自动生成有身份、有记忆、会对话、会行动的智能角色，并驱动整个项目世界持续运行与演化。

## 项目简介

- **世界创作**：手动创建 / 文件解析（AI 七类分段、可选扩写）/ `.holzyn` 导入导出；
- **世界初始化**（6 步全自动）：地点 AI 提取 → 角色卡 → 字段字典 + 普通 NPC → 关系拓扑 → 世界时间 AI 推断 → 知识向量化，失败不阻断、支持幂等重跑；
- **角色体系**：特殊 NPC（结构化角色卡、关系拓扑 AI 生成 + AntV G6 全局拓扑图）+ 普通 NPC（字段字典、批量生成 SSE 预览、两级 AI 调度）；
- **对话**：单聊 / 群聊 SSE 流式、长期记忆抽取与注入、RAG 知识检索、世界事件、场景化对话（所在地 / 世界时间）；
- **世界持续模拟**：世界时钟、角色行动引擎、人群程序化状态机、世界事件、统一时间线、场景化世界演化；
- **界面**：深浅双主题 + 可换肤主色 + 世界题材联动，HarmonyOS Sans 字体与图标。

## 运行方式

**环境要求**：JDK 21、Maven、Node.js（前端构建）。

| 操作 | 命令 |
|---|---|
| Windows 一键运行 | `run.bat`（jar 缺失时自动执行 `build.bat`） |
| macOS / Linux 一键运行 | `./run.sh`（jar 缺失时自动执行 `build.sh`） |
| 完整构建（前端→static→jar） | Windows：`build.bat`；macOS/Linux：`./build.sh` |
| 前端开发（Vite，端口 5174） | `cd frontend && npm install && npm run dev`（代理 `/api`、`/uploads` → 8080） |
| 后端开发（Spring Boot，端口 8080） | `cd backend && run-mvn.bat`（或 `mvn spring-boot:run`） |

**数据说明**：本地 H2 数据库在首次启动时自动创建于仓库根 `data/`，上传文件在 `uploads/`；两者均不入库（见 `.gitignore`），克隆即干净起步。

**首次使用**：启动 → 设置 → API 配置（配置 OpenAI 兼容的 AI 服务）→ 新建项目（手动 / 文件解析 / 导入）→ 世界初始化 → 开始对话。

## 下一阶段开发预告

当前 v0.1 Beta 已具备 对话 / 记忆 / 知识库 / 关系拓扑 / 世界初始化 / 世界模拟 等能力闭环。下一阶段将按**六组件框架**（感知 / 记忆 / 思考规划 / 角色扮演 / 行动 / 学习）演进为「NPC 自决策、自推进」的活世界：

- **世界事件总线 + 感知上下文**：NPC 的行动与事件成为他人可感知的世界状态，决策不再"盲目"；
- **世界推进引擎**：无人值守的持续自推进（含预算控制、统一暂停语义）；
- **普通 NPC 参与对话 + 行动记忆沉淀**：居民从"背景板"变为"活着的个体"；
- **动态关系 / 好感、目标 / 计划 / 反思、决策接入 RAG**：个体智能感与社会动力学；
- **对接游戏引擎**：双向接口（REST 决策 + WebSocket 事件推送）、模型分层路由（特殊 NPC 用好模型、普通 NPC 用一般模型）。

详细设计见 `docs/设计文档/`（六组件框架、缺失功能清单、不自洽与矛盾点清单、闭环评估）。
