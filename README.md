**一句话**：HolzynActor（全境众生）是一台**让世界自己活着的 AI 世界模拟引擎**——你给它一段世界观，它还你一个会自己过日子、自己记事、自己长出故事的世界。

**定位**：为想看见「一个世界真的在运转」的人而做。这里不写剧本、不摆布角色：世界按自己的时钟前进，角色按时作息、互相传话、记住恩怨、随局势改变计划。你可以只在旁边看，也可以走进去说一句话。

**形态与关系**：以「浮生」之名呈现的世界模拟引擎——项目数据存在本机、项目自身没有云端账号体系，但**必须自行配置 AI 模型**才能真正运转；桌面端可看可干预，也可退居为纯 AI 大脑，把实时世界交给引擎客户端接管。它是 Holzyn 全境世界生成体系中的角色与世界驱动内核，本仓库以「全境众生 · 浮生」独立呈现。

## 浮生之约

> 「浮生」二字落在这里：世界不必等你上线，但它记得你来过。五条承诺，每一条都落在已经跑通的机制上。

| 承诺 | 在 HolzynActor 里怎么兑现 |
|---|---|
| ⏳ **你不在，世界也没停笔** | 单一权威世界时钟 + 无人值守自转：世界按自己的节奏推进——角色按时作息、按计划行动、随局势改主意。而你也随时可以让它静止：暂停即冻结，恢复从冻结处接续，**不补算离线**。 |
| 📖 **它会记得** | 四层记忆 + 世界编年史 + 世界记忆：说过的话、走过的路、爱过的人都会留下。记忆会随时间模糊、随睡眠清洗、随巩固升层，也会在需要时被**主动想起**。 |
| 🌱 **它会自己长大** | 全生命周期十阶段 + 人格演化 + 婚育谱系：角色从婴儿走到耄耋，重大事件会真实改变他的性格，结婚生子让家族树继续生长，衰老与身后事都有交代。 |
| 🏘 **它会自己长出一个社会** | 关系网络 + 群体闲谈 + 中观组织 + 宏观社会演化：消息在地理上扩散、在口耳间失真，收成影响粮价、粮价影响生计、生计影响势力。 |
| ✓ **它不会假装成功** | 统一护栏 + 兜底降级 + 独立评审 + 兜底路径验收：模型调用失败会被**降级**而不是被掩盖；世界也不会为了好看而破例。 |

## 核心亮点

- **🧠 真·认知闭环**——感知 → 记忆 → 思考 → 扮演 → 行动 → 学习，由世界运行时统一编排：角色是真的「看见 → 想 → 说 / 做 → 记住 → 成长」，而不是按脚本念台词
- **🌍 活着的世界**——单一权威时钟推动世界前进，每天自动生成世界日报，季节与天气注入感知 / 对话 / 决策三条链路，消息在地理上扩散并在人群口耳间失真
- **🎭 千人千面**——每次决策都注入角色的全量个性：同一件事，稳重者组织乡老议事、勇武者上前查看、医者背起药箱、隐者按兵不动
- **👤 一生一世**——统一角色档案 + 全生命周期十阶段：角色会成长、会成家、会生养、会衰老、会离世，性格也会被经历真实地改写
- **🏛 自己长出来的社会**——收成 → 粮价 → 生计 → 势力的因果链把气候一路传导到饭桌，中观组织自发成组，二阶涌现可检测、可回放
- **🕰 会想、会犹豫、会回来**——高重要度事件先推演几种可能再动；被打断的事有记录，处理完按性格决定回去继续、改变安排还是彻底放弃
- **👁 看得见、🔌 可被接管**——三维沙盘实时看角色的位置、动作与想法，可点击拾取、插话、注入事件、控时、切天气；世界也可退居为纯 AI 大脑，交给引擎客户端主导，断开即冻结、重连从冻结处接续
- **🧪 可被检验 · 📦 项目即文件**——独立评审通道打分（一致性 / 合理性 / 情境利用 / 前瞻性 / 自然度）+ 统一护栏降级 + 兜底不崩；整个世界可导出为单个 `.holzyn` 文件，随身携带、随时还原

## 世界构建与生成

> 从一段世界观文字，到一个已经诞生、带编年史的世界。

- **三种造世界入口**：上传世界观文字交给 AI 自动分段解析；手动分节填写；或交给创意发散生成
- **工作流式世界生成**：多维 AI 工作流分工产出世界设定（部分并行、部分链式），预览确认后落库
- **一键全自动流水线**：设计角色阵容 → 逐角色深度建档 → 世界初始化 → 生成「世界诞生」编年史，全程实时进度
- **角色阵容与建档**：按世界观自动设计核心角色并逐个建档；档案可完整预设，AI 只补缺、不覆盖你写好的部分；世界详情页还可随时单独补生成角色
- **故事规划与风格宪法**：生成「叙事力学」与「世界风格宪法」（语气 / 参照 / 叙事人格 / 戒律 / 题材笔记）——只定义力、不定义事件，再以世界氛围注入环境描写与宏观叙事
- **项目即文件**：整个世界导出为单个 `.holzyn` 文件，可选密码加密，换机器、送人都只需一个文件

## 世界运行与时间演化

> 世界不是等你来才转的，它有自己的时钟。

- **单一权威世界时钟与三周期调度**：以「现实时间 × 速率」推算游戏时间，秒级推进、暂停冻结、随时调速；感知每 5 游戏分钟、主决策每游戏小时、记忆与总结每游戏日，长离线回来自动逐小时补齐
- **每日世界帧**：每天 0 点自动生成一份「世界日报」（逐区域的天气、宏观事件、信息包、环境变化），AI 主生成 + 规则兜底双通道，重大事件可随时紧急更新
- **时间与季节**：季节轮转、气温曲线、天气切换与体感温度；角色的性格参数（怕冷 / 喜雨 / 夜猫子 / 体弱 / 怕热 / 恋家 / 好动）会按环境加权
- **信息扩散与三层过滤**：消息按「距离 × 速度」在各地间传播，沿途被添油加醋地**失真**；每个角色只听到「他够得着、够格听、以他的视角」的版本——谣言、悬赏、传闻在村里真实流动
- **世界运行时语义**：启动全静止，进入沙盘（或被客户端接入）才运行该世界，其余世界一律静止；暂停即时间冻结，恢复从冻结处接续、不补离线
- **编年史、世界记忆与前瞻**：世界事件沉淀为时间线，实体状态按失效规则更新，角色的行动、对话、记忆、关系全部可回溯；另有程序化趋势（粮价 / 民怨 / 势力 / 议题的环比方向）与一句「未来一天世界走向」注入决策

## 角色认知与记忆

> 角色不是「每小时例行做点事」，而是像人一样对世界做出即时反应。

- **六件套闭环**：感知（看见世界）→ 记忆（记住经历）→ 思考规划（有方向）→ 角色扮演（会说话）→ 行动（会做事）→ 学习（会成长）
- **视角化感知**：以角色自己的视角组装世界——时间、所在地、在场者、可见事件、关系摘要、自身状态，加上「他当下够得着、听得到的传闻」；八类刺激源可即时唤醒他
- **四层记忆**：工作记忆 / 经历记忆 / 核心身份 / 长期档案，按情境分层注入、按预算路由
- **记忆会变**：随时间模糊、随睡眠清洗、随巩固从低层升到高层，谱系可追溯；核心身份随经历自编辑演进，反思防止叙事漂移
- **会主动想起，知识也会活**：需要时角色自己检索——角色记忆 + 世界大事记 + 人物知识卡三源检索，带冷却；世界设定与人物知识卡进入可检索知识库，对话会真的引用，知识会淡忘、会被标注「可能过时」，而角色的经历会沉淀成新的知识
- **双通道决策与打断**：周期通道管日常作息，即时通道管突发应对；被打断的事有记录，处理完按性格决定回去继续 / 调整 / 放弃
- **协商与弦外之音**：盯上同一件事会真去谈一次；还会按自己的性格过度解读或直接理解对方的话

## 角色状态与情绪

> 有身体、有情绪；而身体和情绪会反过来影响他做什么。

- **生理四需 + 健康 + 心情**：饥饿 / 口渴 / 精力 / 膀胱与健康值随游戏时间衰减、随行动恢复，长时间运行不吞小数
- **生理会真的打断他**：危险时实时打断，放下手头事去吃饭 / 喝水 / 如厕 / 休息；进食还有三餐窗口
- **PAD 情绪模型**：愉悦 / 唤醒 / 支配三维 + 主导情绪标签与强度；情绪会自然衰减、会写回记忆、会反向影响决策
- **紧急度与能力自评**：派生紧急度文本与 0~3 级，升档即触发即时反应；角色对自己各领域的能力有主观评分（允许自信，也允许谦逊），并随经历微调——偏差本身就是性格
- **社交差异化**：对恩人、旧识、猜忌者的态度有分寸，关系随经历实时变化并反过来影响行为
- **可观察、可调参**：状态历史曲线、实时调参面板，运行时改、重启还原

## 角色生命历程与人格

> 角色不是一个固定的设定文本，而是一段被预设、又会被经历改写的人生。

- **统一角色档案**：身份与社会 / 外貌与体质 / 生理基线 / 气质与人格 / 价值观与动机 / 能力与知识 / 语言与表达（声音指纹）/ 习惯与日常 / 经历与创伤 / 发育·遗传·谱系 / 社会面具
- **全生命周期十阶段**：婴儿 → 幼儿 → 学龄 → 青少年 → 青年 → 壮年 → 中年 → 老年 → 耄耋 → 已故，每阶段有明确的能力门控与行为约束（婴儿不能对话、青少年不得老成持重、老年重体力受限）
- **此刻可发生空间**：程序化硬门控 + AI 软可能性空间（此刻内心 / 可发生状态 / 可发生行为 / 不可发生）——决策必须落在空间内，护栏校验兜底
- **人格演化**：重大事件驱动人格受控偏移，偏移速率与幅度受发育阶段约束，全程留证据链可反查
- **社会面具**：内心与表达分离，对权威 / 伴侣 / 陌生人 / 同伴 / 子女 / 仇怨对象 / 公共 / 私人各有抑制强度；**面具会破绽**——酒精、创伤触发物会让最不该失态的人失态
- **遗传、婚育与谱系**：基因位点重组 + 表观修饰 + 噪声与突变；角色可恋爱、结婚、生育，新生儿的档案按家族与时代环境自主生成，家族谱系可追溯
- **衰老与死亡**：机能曲线随龄衰减、感官退化、疾病风险上升；自然死亡（调试期可关）与身后事——编年史、丧亲记忆、遗产转移
- **认知 LOD**：按「观察强度」而不是「角色总数」分配算力——远离视线且无人相关的角色以更轻的路径维持基本生活，一旦被靠近、被涉及、或与被关注者有直接关系，就自动升档为完整决策，离开后滞回降档

## 社会关系与群体涌现

> 个体之上还有一整个世界在跑：收成会一路传导到每个村民的饭桌上。

- **关系与好感**：关系类型 / 好感 / 信任 / 关系状态随对话、行动、事件三挂钩实时演化，拓扑可视化
- **群聊与自主对话**：单聊、群聊，以及角色之间自己找话题闲聊、回应彼此——对话结束后自动抽取记忆并影响双向关系
- **家族谱系与中观组织**：婚育与继承形成可追溯的家族树；势力、归属、自发成组三类群体自动派生，例行指令与事件指令会注入成员感知
- **宏观社会演化**：人口 / 经济 / 势力的数值引擎 + 文化舆论与科技推进；**收成 → 粮价 → 生计 → 势力**的因果链把气候变化一路传导到饭桌
- **双向联动与行为多样性**：宏观影响个体、个体行动回流宏观；状态涟漪 + 日衰减避免所有人都做同一件事
- **二阶涌现检测与全链路回放**：防自举聚合 + 权重 / 冷却 / 比例控制 + AI 叙事回退；一次宏观推进的输入 / 参数 / 事件 / 回灌四跳可回放，调参不靠猜

## 世界沙盘与实时干预

> 你可以只是看着，也可以伸手推一把。

- **三维实时沙盘**：像素地形、模型摆放、角色光环与名牌、天气粒子、昼夜光照——村落是真的立在那里
- **实时通道**：角色的位置、动作、想法实时流动，时钟条实时跳动，世界动态即时广播
- **点击拾取**：点角色看他的状态与关系，点建筑看它的位置与用途
- **干预手段**：插话（角色会真的回应）、触发行动、注入事件、控制时间与倍速、切换天气
- **决策链路可回看**：一次决策的「感知 → 思考 → 行动 → 学习」完整链路可逐环节打开，AI 调用详情结构化呈现
- **可观测性**：用量看板、漂移度量、数据巡检、护栏与路由、Prompt 工程指标——世界为什么这么做，有据可查

## 外部接入与质量保障

> 它可以是世界本身，也可以是别人世界背后的大脑。

- **引擎接管**：HolzynActor 可退居为纯 AI 大脑，把实时世界交给 Unity 客户端主导——统一消息契约、心跳看门狗、序号幂等对账、断线重连续传
- **客户端拨钟**：客户端上报游戏时刻驱动世界推进；断开即世界冻结，重连从冻结处接续、**不补离线**
- **上报即感知**：玩家视野与交互作为新的刺激源，角色会因此被打断、改变计划
- **环境与坐标**：客户端上报的天气环境就地生效并联动环境刺激；客户端格子坐标与服务端语义位置双向换算（1 格 = 0.2 米）；一次性全量初始化下发 + 干预薄代理，客户端不必理解内部模型
- **原生鸿蒙端**：ArkTS + ArkUI + 本地数据库，业务与数据 100% 本地化，功能对齐桌面主线的独立实现 → [HolzynActor_HarmonyOS](https://github.com/hongyun1312/HolzynActor_HarmonyOS)
- **可被检验**：行为质量由**独立评审通道**按五维打分（一致性 / 合理性 / 情境利用 / 前瞻性 / 自然度），样本去标识、位置打散，避免自己评自己
- **不会假装成功，也不会停摆**：空输出、复读机、连续失败、超时统一拦在护栏里并降级到兜底路径——模型不可用时世界不会崩、不会假装成功，但**会明显变得僵硬**；这条兜底路径有专门验收守住
- **长跑与跨日验证**：多轮真实长跑（跨自然日、跨小时边界、断线重连）逐轮抓缺陷并留下可复现证据

## 快速开始

前置：JDK 21 与 Node.js 20+。

```bash
git clone <仓库地址> HolzynActor && cd HolzynActor
run.bat            # Windows（macOS / Linux 用：bash run.sh）
# 然后打开 http://localhost:8080
```

- 首次启动会引导你建立本地账户；进入项目画廊即可新建项目，或直接打开仓库内附带的世界
- **进入设置配置一个模型接口**（OpenAI 兼容 API 或本地模型）——这是让世界正常运转的前提，不配模型只能看到僵硬的兜底状态，详见[常见问题](#常见问题)
- 世界默认**启动全静止**：进入沙盘（或由引擎客户端接入）后该世界才开始运行，其余世界保持静止
- 想了解构建、数据约定等工程细节，见仓库内脚本与 `docs/`

## 常见问题

<details>
<summary><b>需要联网吗？我的数据会被传到哪去？</b></summary>

**必须配置 AI 模型才能正常使用。** 世界的推进、角色的决策与对话、世界设定的生成、记忆与知识的检索，**全部依赖模型调用**——模型可以是你自己部署的本地模型，也可以是云端 API，用得越强，世界越像真的。

**程序化只是兜底，不是使用方式。** 不配模型时世界不会崩，但那是一种退化状态：角色会退回机械的作息循环，行动僵硬、对话空洞、互相之间几乎不会真的发生什么，**非常不真实**。它存在的意义只有一个——让模型抖动或失败时不至于把世界弄坏。想要「像真人一样生活」的世界，就必须把模型配上。

数据方面：项目数据（世界观 / 角色 / 记忆 / 对话 / 沙盘）默认存在本机，项目自身没有云端账号体系；只有你自己配置的模型接口会收到为生成内容而发送的提示词。
</details>

<details>
<summary><b>我关掉之后，世界会乱吗？</b></summary>

不会。暂停即时间冻结，恢复时从冻结处接续、**不补算离线**；世界静止时记忆蒸馏、批量巩固、归档、清扫等后台任务全部不发生，所以不会出现「回来一看过了一百年」的失控。
</details>

<details>
<summary><b>角色做得不像人 / AI 出错了怎么办？</b></summary>

系统有三道保险：统一护栏（空输出、复读、连续失败、超时都会被拦下并降级）、兜底降级（模型失败时角色仍有一个不崩的默认行为，但会显得僵硬）、独立评审（由另一条通道给行为质量打分，自己评自己会失真）。当然，本项目仍在开发中，**请不要过度信任 AI**。
</details>

<details>
<summary><b>能只跑一个小村子吗？规模可以多大？</b></summary>

目前项目还在处于完善开发阶段，测试的都是村庄级别的世界，没有进行大规模的世界测试，并且项目的部分功能仍以村庄级别进行设计的，所以大规模的世界请谨慎运行，开发者不保证项目运行的稳定性。

青禾村（约百米见方、20 位角色、15 处地点）就是长期使用的测试世界，用来把机制压到最真实。规模可以继续放大，但角色越多、决策越密，对算力和时间的要求越高。
</details>

<details>
<summary><b>这是游戏吗？我能做什么？</b></summary>

不是传统意义上的游戏，而是一台**可看、可干预、可接管**的世界模拟引擎：你可以旁观它自己运行，可以走进去说一句话、推一件事件，也可以把实时世界交给引擎客户端去渲染和主导。
</details>
